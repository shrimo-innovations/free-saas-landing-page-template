# SaaS Landing Page Starter Template

A free HTML + Tailwind CSS starter template for creating a simple SaaS landing page website.

This template is suitable for software products, SaaS tools, CRM platforms, CMS products, LMS portals, admin dashboards, automation tools, and demo projects.

## Preview

Open `index.html` in your browser to preview the template.

You can also deploy it on GitHub Pages, Netlify, Vercel, cPanel hosting, or any static hosting provider.

## Pages Included

- `index.html` - Homepage
- `features.html` - Product features page
- `use-cases.html` - Use cases page
- `pricing.html` - Pricing page
- `faq.html` - FAQ page
- `contact.html` - Contact and demo request page
- `login.html` - Login page

## How to Use

1. Download and unzip the template.
2. Open `index.html` in your browser.
3. Edit the HTML content as needed.
4. Replace demo links, product details, pricing, and contact details.
5. Connect forms to your backend or API if needed.

## GitHub Pages Auto Deployment

This template includes a GitHub Actions workflow at:

```text
.github/workflows/static.yml
```

To enable automatic deployment:

1. Push this project to your GitHub repository.
2. Open your repository on GitHub.
3. Go to `Settings → Pages`.
4. Under `Build and deployment`, set `Source` to `GitHub Actions`.
5. Push changes to the `main` branch.

After setup, every push to `main` will automatically deploy the template to GitHub Pages.

For this repository:

```text
Repository:
https://github.com/shrimo-innovations/free-saas-landing-page-template

GitHub Pages URL:
https://shrimo-innovations.github.io/free-saas-landing-page-template/
```

If the site does not appear immediately, check the `Actions` tab in GitHub for deployment status.
